Windows setup guide

Ollama and a supported AI model are compulsory prerequisites for Panda's local AI features. Panda's installer does not include Ollama or the multi-gigabyte model. You need an internet connection to download them and adequate free disk space for the model.

  1. Install Ollama for Windows.
  2. Open Ollama and make sure its local server is running. See the official Ollama documentation if needed.
  3. Open PowerShell and run: ollama pull qwen3.5:2b.
  4. Wait for the model download to finish.
  5. Install and launch Panda Companion.
  6. In Panda Settings, choose Local Ollama and click Refresh.

Local inference runs on your computer using Ollama and the model you installed. Screen content should only be shared after you explicitly start sharing. Capture and live-session behavior remain experimental and have not been fully verified on Windows.

Experimental / beta

This project is not production-ready. Windows screen capture, live-session Pause/Stop behavior, and screen-to-vision flow still require real Windows verification.

Supported system

Windows 10 or 11, x64 desktop. Hardware and available memory affect local model performance. WebView2 may be installed by the Panda installer if missing.

Installation after release

When a verified release is available, download the Windows installer from the linked release page. Unsigned builds may show a Windows SmartScreen warning.
